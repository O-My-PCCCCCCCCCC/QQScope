\# 项目介绍文档



\## 项目简介



本项目于2026年5月提出构想并创建仓库，直到最近才正式着手开发。



这是一款用于读取 QQ 聊天记录并自动分析心理状况等内容的玩具项目。除此之外，我们还实现了一些附加功能，例如仿 QQ 本体的聊天对话框，以及一个更加便捷的聊天记录导出工具。



\## 技术架构



\- \*\*冷处理方案\*\*：利用 QQ 首次登录所产生的 token 来解密本地聊天数据。

\- \*\*热处理方案\*\*：借助 NapCat 这一 QQ 聊天机器人框架实现热更新，用于及时同步聊天记录。



\## 当前存在的问题
